# Waterwood Lodge: concept site (staging)

Concept website prepared by Conversion Advantage for discussion with Waterwood Lodge. It is a mockup: rates, offers and the booking step are placeholders, and the enquiry form does not send anything.

- `index.html` is the whole site in one file, with the pictures built in.
- The page is marked `noindex` so search engines leave it out.
- The working copy lives in the Conversion Advantage Drive folder `waterwood-lodge-poc/website/`. Change it there, then copy it here and push.
